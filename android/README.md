# 📶 EasyCellular for Android

Точная диагностика сотовой сети на Android 17 (API 37): тип сети с признаком 5G+, сигнал по каждой вышке (RSRP / RSRQ / SINR), диапазон, PCI, канал, оператор, SIM и eSIM, пинг, скорость и история.

## 🚀 Сборка через GitHub Actions

1. Создайте репозиторий и залейте в него содержимое архива (папка `android/` внутри монорепо, подробнее в README в корне).
2. Откройте **Actions → Build Android APK**. Сборка запускается при push в `main`.
3. Скачайте артефакт **EasyCellular-APK** (файл `app-debug.apk`).
4. Установите APK на телефон. Разрешите установку из неизвестных источников.

Локально: откройте проект в Android Studio (Ladybug или новее), установите SDK Platform 37 и нажмите **Run**.

## 🔐 Разрешения

| Разрешение | Зачем |
|---|---|
| `READ_PHONE_STATE` | Тип сети, 5G+, SIM, сигнал, роуминг |
| `ACCESS_FINE_LOCATION` | Данные вышек (`allCellInfo`). Android требует геолокацию для Cell ID и диапазона |
| `INTERNET`, `ACCESS_NETWORK_STATE` | Пинг и тест скорости |

Без разрешений приложение работает, но показывает только то, что Android отдаёт без них.

## 🧭 Что показывает

- **Сеть:** тип 2G / 3G / 4G / 5G / 5G+, канал, Wi-Fi или нет сети
- **Сигнал:** RSRP, RSRQ, SINR, качество с цветовой оценкой
- **Вышка:** диапазон, PCI, EARFCN или NR-ARFCN, Cell ID, TAC, ширина канала
- **Оператор и SIM:** оператор, MCC-MNC, страна, роуминг, все SIM и eSIM
- **Подключение:** канал, интернет проверен, лимитный трафик, макс. скорость по линку, IP, DNS, MTU
- **Тест:** пинг с джиттером и потерями, загрузка и отдача через выбранную сеть
- **Устройство:** определение платформы (Android / iOS), версия, API, патч безопасности

- Язык: русский или английский
- Хост для пинга
- Очистка истории

## 🧪 Точность

- **5G+** определяется по `TelephonyDisplayInfo` (NR Advanced). Это официальный признак оператора. Если оператор его не передаёт, 5G+ появится после теста со скоростью от 500 Мбит/с (порог в `SpeedConfig`).
- **RSRP / SINR** берутся у каждой вышки отдельно через `CellSignalStrength`, а не выводятся из уровня полосок.
- **Скорость** считается по нескольким параллельным потокам через выбранную сеть, первые 2 секунды не учитываются.
- **Пинг** измеряется как время TCP-подключения к `1.1.1.1:443`, потому что ICMP без root недоступен.

> ⚠️ Тест скорости расходует трафик. На канале 1 Гбит/с один запуск может потратить около гигабайта.

## 🌍 Добавить язык

1. В `i18n/Strings.kt` добавьте код в `enum class Lang`.
2. Для каждого ключа добавьте перевод. Недостающий ключ покажется как есть, без падения.

## 🛠 Версии

- minSdk 31 (Android 12), targetSdk и compileSdk 37 (Android 17)
- Kotlin 2.1.0, Compose BOM 2025.01.00, AGP 8.9.1

Если при сборке AGP пишет, что compileSdk 37 не протестирован, обновите AGP до более новой версии в корневом `build.gradle.kts`.
